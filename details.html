Complete Manual Testing Handbook

1. Introduction to Software Testing

Software Testing: Process of verifying and validating software to ensure the application works according to requirements.

Goal: Find bugs, improve quality, increase reliability, and deliver a stable product.

Why Testing is Important?

  • Improves software quality
  • Prevents production bugs
  • Enhances user experience
  • Reduces maintenance cost
  • Ensures business requirements are met

4. Types of Testing

Functional Testing

Testing application functionality according to requirements.

Regression Testing

Ensuring new changes do not affect existing functionality.

Smoke Testing

Basic testing to verify critical features are working.

Sanity Testing

Checking whether specific bug fixes or modules work correctly.

UI Testing

Verifying design, buttons, alignment, responsiveness, and layout.

Compatibility Testing

Testing application on different browsers, devices, and OS.

Performance Testing

Checking speed, stability, and responsiveness under load.

Security Testing

Ensuring application is protected from vulnerabilities.

Database Testing

Validating data storage, retrieval, and database integrity.


5. Black Box & White Box Testing

Black Box Testing: Testing without knowledge of internal code.

White Box Testing: Testing internal code structure and logic.

15. Manual Testing Interview Questions

Q: What is Manual Testing?

Manual Testing is the process of testing software manually without automation tools.


Q: Difference between Smoke and Sanity Testing?

Smoke testing checks major functionality, while sanity testing checks specific functionality after changes.


Q: What is Regression Testing?

Regression testing ensures existing features are not affected after new changes or bug fixes.


Q: What is a Bug?

A bug is a defect where actual result differs from expected result.


Q: What tools have you used?

JIRA, Postman, Browser DevTools, Grafana, and SQL databases.


16. Best Practices for Testers

  • Understand requirements clearly
  • Write detailed test cases
  • Always verify bug fixes
  • Test edge cases
  • Maintain proper documentation
  • Communicate clearly with developers
  • Focus on user experience

17. Conclusion

Manual testing is essential for delivering stable and high-quality software. A skilled tester ensures better user experience, reduced production issues, and reliable software releases.
